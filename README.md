# Redux Toolkit practice

A learning "Watchlist" app: add movies, mark them as watched, and see a counter of watched titles.

**Stack:** React, TypeScript, Vite, Redux Toolkit, React-Redux.

**Run:** `npm install` → `npm run dev`

**Covered:** configureStore, createSlice, typed hooks (useAppSelector / useAppDispatch), selectors, createAsyncThunk, RTK Query.

**Also:** TV show search (TVMaze API) implemented twice, with `createAsyncThunk` and with RTK Query, to compare the two approaches.
